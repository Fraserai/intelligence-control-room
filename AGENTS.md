# AGENTS.md — "Omarchy for AI" (working name)

This file is Caesey's vision in Caesey's own words. Build exactly this. Don't add, remove or change anything in the vision without Caesey's approval. If you think something should change, ask first.

## The vision

Omarchy for AI: one place that's sexy, fully malleable, agentic and fully customisable. The single command centre for my AI world and daily work.

DHH built Omarchy as an operating system that's opinionated, beautiful, changeable, fully controllable and customisable, and the system itself is agentic and built for agents to use. This is that, for my AI world.

It would have every LLM, so ChatGPT, Claude, Grok and Gemini, with all the features they already have. Then it would also have Claude Code, Codex and OpenCode, and you could bring all of those into it. It would have all of the inference providers and all of the open and closed models, in one sexy place, agent first. The system itself would be agentic.

I'm not trying to recreate ChatGPT, Claude or Grok. I want to see all of the inference providers at a deep level, all the coding agents, all the LLMs and all the models, and work with them how I want. They can work together. It's all agentic first, all in one place, and sexy. If it's just websites in tabs, why not just use Chrome?

It would have all my context and memory and the way I work, from my last four years of daily AI work, shared across all of the LLMs, all of the coding agents and all of the tools.

It's not built just for developers or programmers. It's built for a cracked AI power user who's deep in AI and has used it since 2022.

Use lots of open source that will help make this great. Take the simple gems and features we like from projects like T3 Code and Omarchy (both open source), and use them to make this exact vision real.

Don't fork anyone's codebase as our base, because then it's theirs. There are probably beautiful open-source layouts that are perfect for this product and make it beautiful. Use what's out there and build new, both.
